* Commissioning plan generation and dose-analysis use case
The software should support generating the plan data for a commissioning test suite, calculating it in Monaco, and comparing returned calculated data against measured data.
MPPG 5.b is the first example protocol to map; the workflow should also support other explicitly defined commissioning protocols.
Source: [[https://doi.org/10.1002/acm2.13641][AAPM MPPG 5.b (2022), Commissioning and QA of treatment planning dose calculations: megavoltage photon and electron beams]].
- Build a source-linked coverage matrix from the guideline test list to required phantom geometry, beam configuration, calculation settings, measurements, extraction methods, and review requirements.
- Map modeling/basic photon checks (Tables 4-6), heterogeneity (Table 7), IMRT/VMAT (Tables 8-9), electrons (Table 10), and routine QA reference plans (Section 9), recording applicability and external/manual steps for each test.
- Generate a blank synthetic DICOM CT volume with configurable voxel/slice spacing (5 mm as the requested example), physical extent, origin, orientation, and HU/material assignments.
- Generate the required phantom structures, density overrides, valid identifiers, and Monaco studyset/plan data from that starting volume.
- Keep image sampling independent of dose calculation grid size; support a requested 1 mm calculation grid with configurable Monte Carlo uncertainty value and mode.
- Generate explicit beam/test matrices covering selected machines and energies, SSDs, field sizes, depths, oblique incidence, asymmetric fields, and other protocol-specific cases.
- Write separate, traceable Monaco plans for each test geometry, with the requested beam shapes, MU/prescription, calculation settings, and relevant density properties.
- Read the calculated plans and dose data back into Python and associate every result with the exact generated case and calculation configuration.
- Verify returned beam geometry, calculation settings, calculation completion, and dose freshness before interpreting the calculated dose as that case's result.
- Extract PDDs, profiles, point-dose or detector-volume samples, and output factors using explicit coordinates, sampling rules, depth/surface definitions, and reference-field geometry.
- Import measured data with explicit units, measurement geometry, normalization, detector information, and provenance, and compare like-for-like with the calculated results.
- Generate comparison plots, numerical differences, configurable protocol-specific acceptance checks, and a reviewable coverage/results report.
- Preserve guideline edition/test identifiers, Monaco version, beam-model identity, source and returned file hashes, image/dose grids, uncertainty settings, and dose/MU/fraction normalization in the result provenance.
- Identify test requirements needing acquired images, real measurements, or external end-to-end validation rather than claiming a synthetic dataset completes the entire commissioning process.

- Implement a Python importer for Monaco-exported DICOM dose as an initial return path, independently of later native compressed-dose support.

*** Measurements, comparisons, and coverage reporting
- Validate measured-data import preserves raw values, units, detector metadata, measurement geometry, profile direction, normalization, and provenance, including any corrections already applied.
- Validate case matching and comparison calculations with independently calculated examples; preserve the distinction between pointwise dose differences, distance-based measures, and other protocol-specific metrics.
